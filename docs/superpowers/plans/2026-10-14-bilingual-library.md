# 中英文提示词库实施计划

设计与验收：docs/superpowers/specs/2026-10-14-bilingual-library-{design,acceptance}.md。

1. 基础：集中翻译辅助函数／界面字典，双语目录投影和页面语言，语言切换的真实对应路径。保留来源原文，不重复导入数据。
2. 界面：共享页头页脚、图片／视频／网站全部层级、筛选／空态／可访问名称和目录双语。界面实施子任务可由一个隔离上下文实现者处理；文件所有权明确，不并发修改同一文件。
3. 导出：双语回执、图视图及目录JSON，静态验证兼容两种语言；补齐路由／语言切换／正文不变／浏览器回归。
4. 审查及发布：独立审查，远端检查，合并后构建与测试站双分支发布，线上双语验收。

Ruling: 翻译产品界面和导航分类；原作者正文以及缺少来源译文的标题／介绍作为原始资料保留并标注语言。用户没有要求改写提示词，避免影响复制使用或伪造作者译文。正式域名接入继续暂缓。
Ruling: 延续用户此前已明确授权的推送、创建合并请求、合并和测试站发布；不重复询问许可。原始工作目录中的并发修改保持不动。
