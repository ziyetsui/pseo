# 提示词库中英文版本设计

用户明确要求增加中文和英文版本，延续已授权的代码推送、合并和测试站发布流程。基线采用最新已合并7c4ae8a，包含另一会话补充的网站提示词，不回退数据。

- 提供 /zh-CN/prompts 与 /en/prompts 及同层级完整路由，页头提供中文／English切换入口。切换保持同一对象、层级、有效筛选参数和页内锚点，禁用脚本仍可切换到对应干净路径。
- 中文页面的界面、按钮、筛选、统计、空态、无障碍标签、页脚、目录及分类说明使用中文；英文页面使用英文。模型、工具、作者名称、代码和提示词原文保留原样，正文明确标注原文语言。
- 集中维护类型安全的界面字典、数量格式和语言路由辅助函数。服务端直出对应语言，不依赖翻译覆盖层或修改已渲染DOM。已有图片／视频／网站各层级原型及交互保持。
- 两种语言共享不可变内容标识、图关系及来源；只改变展示与对应路径。提示词正文不自动翻译，不冒充作者译文。尚无双语来源的案例标题／介绍属于原始资料，明确保留原文语言，不伪造内容审核状态。
- 两种语言的完整目录、导出回执、静态验证分别绑定同一数据版本。保留现有中文目录JSON地址，新增英文目录JSON。全部测试站页面保持禁止搜索引擎收录；ancher.ai接入按用户要求暂缓。
