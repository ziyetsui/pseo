# 中英文版本验收

1. 两种语言生成相同对象及图视图集合；未知语言／对象返回404；中文和英文地址均可直接访问、刷新。
2. 页面html与body语言一致；页头、核心标题、类别、筛选、按钮、统计、页脚、目录、可访问名称分别显示所选语言。0个中文界面关键操作残留英文，0个英文界面关键操作残留中文。
3. 语言切换100%对应同一对象，保持有效查询和锚点；无脚本时对应干净路径可用。
4. 提示词正文、变量、来源链接、作者和代码逐字保持；原文语言与界面语言独立标识；不宣称缺失的译文已审核。
5. 图片／视频／网站的入口、用途、模型／技术、详情、目录代表页在两种语言及375/768/1440宽度通过；键盘、筛选／历史、无脚本、无障碍和原型结构不回退。
6. 每种语言的目录JSON与服务端目录一致，全部内部链接及图范围通过独立静态校验；页脚只链接对应语言真实路由。
7. 类型检查、单元测试、构建、静态校验、独立审查、远端检查和合并提交发布通过；保存部署标识与实际线上回执，不将代码合并冒充上线。
