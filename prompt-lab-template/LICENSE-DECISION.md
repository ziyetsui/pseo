# License decision required

The owner must choose and install licenses before making the real Prompt Lab repository public. This is a legal and product decision; the template does not guess it.

Decide separately whether the repository's software and contributed Prompt content use the same terms. Common options may have materially different attribution, commercial-use, share-alike, patent, and model-training effects. Obtain appropriate legal advice.

Before launch:

1. Confirm the GitHub owner and repository name.
2. Confirm the license for generator code.
3. Confirm the license for Prompt content and translations.
4. Replace `LICENSE` with the exact approved text and update the contribution form's rights statement if needed.
5. Record the decision and effective date in this file or project governance documentation.

Do not describe the repository as open source or open content while the placeholder remains.
