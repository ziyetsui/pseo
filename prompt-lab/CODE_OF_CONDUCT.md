# Code of Conduct

## Our standard

Be respectful, specific, and constructive. Welcome contributors regardless of background or experience. Critique content and evidence, never people. Do not harass, threaten, discriminate, expose private information, or submit abusive or deceptive Prompt content.

## Enforcement

Repository maintainers may edit or remove contributions, comments, issues, or accounts that violate this standard. Report conduct concerns privately using the contact method configured by the repository owner before launch; do not expose sensitive details in a public issue.

## Scope

This standard applies in repository discussions, reviews, issues, and other spaces where someone represents the project.

This concise project policy must be replaced or confirmed by the repository owner before public launch, including a private enforcement contact.
